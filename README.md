# DSM-5-TR 心理健康自我覺察系統

這是一個使用 **Java Swing** 製作的桌面視窗程式，主題為「DSM-5-TR 心理健康自我覺察系統」。使用者可以輸入基本資料，選擇目前身分、主要困擾與持續時間，系統會依照選項產生初步提醒與求助建議。

> ⚠️ 本系統僅供自我覺察與求助參考，不能取代精神科醫師、身心科醫師、臨床心理師或諮商心理師的正式診斷與治療。

## 專案特色

- 使用 Java Swing 建立桌面 GUI 介面
- 提供姓名、年齡、目前身分、主要困擾、持續時間等欄位
- 使用下拉選單降低輸入錯誤
- 具備基本防呆檢查，例如：
  - 姓名與年齡不可空白
  - 年齡必須為數字且大於 0
  - 必須完成身分、困擾與持續時間選擇
- 依照主要困擾產生初步心理健康提醒
- 提供醫療協助建議與危機提醒
- 支援清除重填、使用說明、儲存提示、列印結果與關閉系統
- 顯示即時系統時間

## 功能說明

### 1. 基本資料輸入

使用者可以輸入：

- 姓名
- 年齡
- 目前身分
- 主要困擾
- 持續時間

### 2. 主要困擾分類

目前可選擇的困擾包含：

- 情緒低落
- 焦慮
- 心悸胸悶
- 睡眠困擾
- 壓力過大
- 創傷經驗
- 強迫想法
- 注意力不集中 / 衝動
- 人際關係困擾
- 家庭 / 伴侶關係困擾
- 飲食或體重困擾
- 身體不適但檢查無明顯原因
- 物質使用 / 酒精或藥物困擾
- 自傷或自殺想法
- 其他

### 3. 分析結果

按下「開始分析」後，系統會輸出：

- 基本資料摘要
- 可能相關狀況
- 持續時間提醒
- 醫療協助建議

### 4. 其他按鈕功能

| 按鈕 | 功能 |
|---|---|
| 開始分析 | 根據使用者輸入產生初步提醒 |
| 使用說明 | 顯示操作步驟 |
| 清除重填 | 清空所有欄位與結果 |
| 儲存紀錄 | 顯示資料已儲存的提示訊息 |
| 列印結果 | 列印分析結果文字 |
| 關閉系統 | 結束程式 |

## 使用技術

- Java 11
- Java Swing
- AWT Event Handling
- Eclipse IDE

## 執行方式

### 方法一：使用 Eclipse 執行

1. 開啟 Eclipse
2. 選擇 `File` → `Import`
3. 選擇 `Existing Projects into Workspace`
4. 選擇本專案資料夾
5. 開啟 `src/com/DSM5TRUI.java`
6. 按下 `Run` 執行程式

### 方法二：使用命令列執行

在專案根目錄執行：

```bash
javac -encoding UTF-8 -d bin src/com/DSM5TRUI.java src/org/*.java
java -cp bin com.DSM5TRUI
```

## 注意事項

- 本專案為學習與展示用途，並非正式醫療系統。
- 程式產生的文字僅作為自我覺察參考。
- 若使用者出現自傷或自殺想法，應立即尋求專業協助、聯絡 1925 安心專線、119 或前往急診。
- 若要讓「儲存紀錄」真的保存成檔案，需要另外加入檔案輸出功能，目前程式是顯示儲存提示訊息。
